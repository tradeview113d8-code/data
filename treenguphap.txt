1. CHÚ THÍCH

CL    = Mệnh đề
S     = Chủ ngữ
P     = Vị ngữ
O     = Tân ngữ
O1    = Tân ngữ 1
O2    = Tân ngữ 2
C     = Bổ ngữ
A     = Trạng ngữ
VOC   = Hô ngữ
INSERT = Thành phần chêm xen

N     = Danh từ
V     = Động từ
Adj   = Tính từ
Adv   = Phó từ
Pro   = Đại từ
Num   = Số từ
Q     = Lượng từ
Prep  = Quan hệ từ
Conj  = Liên từ

NP    = Cụm danh từ
VP    = Cụm động từ
PP    = Cụm giới từ
AP    = Cụm tính từ
AdvP  = Cụm phó từ

REL   = Mệnh đề quan hệ
CONT  = Mệnh đề nội dung
CAUSE = Mệnh đề nguyên nhân
CONS  = Mệnh đề kết quả
COND  = Mệnh đề điều kiện
PURP  = Mệnh đề mục đích
CONTR = Mệnh đề đối lập
COORD = Đẳng lập

AUX   = Trợ động từ
PASS  = Bị động
CAUS  = Sai khiến


2. TREE-GRAMMAR-DEMO
CL
│
├── I. CẤU TRÚC CÂU LÕI
│   │
│   ├── S + P
│   ├── S + P + O
│   ├── S + P + C
│   ├── S + P + O + C
│   ├── S + P + O + A
│   ├── S + P + O1 + O2
│   ├── S + P + A + O
│   ├── S + P + C + A
│   ├── S + P + O + O
│   ├── S + P + O + C + A
│   ├── S + P + O + REL
│   ├── S + P + O + CONT
│   ├── S + P + O + O + A
│   ├── S + P + O + C + REL
│   ├── S + P + O + C + CONT
│   ├── S + P + O + O + REL
│   ├── S + P + O + O + CONT
│   ├── S + P + O + C + A + REL
│   ├── S + P + O + O + C
│   ├── S + P + O + O + C + A
│   ├── S + P + O + O + C + REL
│   ├── S + P + O + O + C + CONT
│   ├── S + P + O + O + C + A + CONT
│   ├── S + P + O + O + C + A + REL + CONT
│   ├── S + P + O + O + C + A + REL + CONS
│   ├── S + P + O + O + C + A + REL + PURP
│   ├── S + P + O + O + C + A + REL + CONT + CONS
│   ├── S + P + O + O + C + A + REL + CONT + PURP
│   ├── S + P + O + O + C + A + REL + CONT + CAUSE
│   ├── S + P + O + O + C + A + REL + CONT + COND
│   ├── S + P + O + O + C + A + REL + CONT + CONTR
│   ├── S + P + A + C
│   ├── S + INSERT + P + O                     ← THÊM MỚI
│   └── S + P + INSERT + O                     ← THÊM MỚI
│
├── II. CẤU TRÚC ĐẶC BIỆT
│   │
│   ├── V + NP + LOC
│   ├── LOC + P + S
│   ├── P + O + A                             ← THÊM MỚI (mệnh lệnh vắng S)
│   ├── S + AUX + V
│   │   └── PASS
│   ├── S + AUX + V + C
│   ├── S + CAUS + O + V
│   ├── S + CAUS + O + V + NP
│   ├── S + P + Adj
│   └── S + P + Adj + A
│
├── III. CẤU TRÚC VỚI THÀNH PHẦN MỞ RỘNG
│   │
│   ├── A + CORE
│   ├── CORE + A
│   ├── S + A + P + O
│   ├── S + P + O + A
│   ├── S + P + AdvP
│   ├── S + P + O + AdvP
│   ├── VOC + CL                              ← THÊM MỚI
│   └── CL + VOC                              ← THÊM MỚI
│
├── IV. CẤU TRÚC NP
│   │
│   ├── N
│   ├── Q + N
│   ├── Num + N
│   ├── N + M
│   ├── Q + N + M
│   └── NP + REL
│
├── V. CẤU TRÚC VP
│   │
│   ├── V
│   ├── Adv + V
│   ├── AUX + V
│   ├── V + NP
│   ├── V + PP
│   ├── V + NP + PP
│   ├── V + NP + C
│   └── V + CL
│
├── VI. MỆNH ĐỀ PHỤ
│   │
│   ├── SC + MC
│   ├── MC + SC
│   ├── TIME
│   │   ├── TIME + CL
│   │   └── CL + TIME
│   ├── CAUSE
│   │   ├── MC + CAUSE
│   │   └── CAUSE + MC
│   ├── CONS
│   │   └── MC + CONS
│   ├── COND
│   │   └── COND + MC
│   ├── PURP
│   │   └── MC + PURP
│   └── CONTR
│       └── CONTR + MC
│
├── VII. MỆNH ĐỀ LÀM THÀNH PHẦN
│   │
│   ├── V + CONT
│   ├── V + REL
│   ├── CONT + P + O
│   ├── NP + REL
│   └── O + REL
│
└── VIII. CẤU TRÚC ĐẲNG LẬP
│
├── CL + COORD + CL
├── S + P + COORD + P
├── O + COORD + O
└── NP + COORD + NP
