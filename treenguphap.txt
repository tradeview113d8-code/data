

1. CHÚ THÍCH

CL    = Mệnh đề
S     = Chủ ngữ
P     = Vị ngữ
O     = Tân ngữ
O1    = Tân ngữ 1
O2    = Tân ngữ 2
C     = Bổ ngữ
A     = Trạng ngữ

N     = Danh từ
V     = Động từ
Adj   = Tính từ
Adv   = Phó từ
Pro   = Đại từ
Num   = Số từ
Q     = Lượng từ
Prep  = Quan hệ từ
Conj  = Liên từ

NP    = Cụm danh từ
VP    = Cụm động từ
PP    = Cụm giới từ
AP    = Cụm tính từ
AdvP  = Cụm phó từ

REL   = Mệnh đề quan hệ
CONT  = Mệnh đề nội dung
CAUSE = Mệnh đề nguyên nhân
CONS  = Mệnh đề kết quả
COND  = Mệnh đề điều kiện
PURP  = Mệnh đề mục đích
CONTR = Mệnh đề đối lập
COORD = Đẳng lập

AUX   = Trợ động từ
PASS  = Bị động
CAUS  = Sai khiến
